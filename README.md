# Personal Portfolio Website

A modern personal portfolio and digital presence built to showcase projects, skills, experience, and ongoing work in AI automation, development, and growth systems.

## Overview

This website serves as my central online portfolio where I showcase:

* Projects and case studies
* AI automation systems
* Web development work
* SaaS experiments
* Technical skills
* Growth and outbound systems
* Contact and collaboration information

The goal of this website is to create a clean, fast, and professional online identity while documenting ongoing projects and learning.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/yourusername/your-repo.git
```

Move into the project directory:

```bash
cd your-repo
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
